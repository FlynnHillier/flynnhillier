# Hey, I'm Flynn 👋

Full-stack developer and final-year BSc Computer Science with AI student at the University of Liverpool.

I like building systems that run themselves: automations, tooling, and lately agents that do much of the building with me.

## 🤖 How I build

I learned to code the long way, by hand. Nowadays almost all my development goes through AI agents. I lean on them to pressure-test my ideas and do the heavy lifting, while the decisions that shape a system stay mine. My philosophy: delegate the work, never the ownership or the understanding.

The field is evolving rapidly, so I make a point of keeping up, experimenting and teaching myself as it changes. Software factories are where I'm looking to explore next.

I'm also a habitual automator: if something is repetitive, I'll probably end up trying to build a tool to do it for me.

## 📖 Background

I've been teaching myself to code through side projects for ~7 years, from full-stack web apps to plenty of automation.

Until early this year I worked as a software engineer at [SparkLayer](https://www.sparklayer.io/) for a 13 month Year in Industry placement. Sparklayer adds B2B features to merchant's stores already setup on existing e-commerce platforms like Shopify, Wix and more. 

While I was there, I:

- Built [B2B Catalogs](https://apps.shopify.com/sparklayer-b2b-catalogs) end to end, a Shopify app with 500+ installs and a 5-star rating on the Shopify App Store
- Led the revamp of our Wix integration, rolling out a new onboarding flow to improve the install-to-live conversion rate
- Rewrote our Unleashed ERP integration in Go, a language new to me at the time
- Pitched AI coding tools, ending in a company-wide rollout
